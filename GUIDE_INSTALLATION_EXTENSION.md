# 🛡️ Guide d'Installation de l'Extension AegisScan

Ce guide explique comment installer l'extension de navigateur AegisScan pour activer la protection et l'analyse des liens en temps réel.

## 📋 Prérequis

1. L'application AegisScan doit être en cours d'exécution.
2. Vous devez être connecté à votre compte utilisateur sur l'application (`http://localhost:5173`).

## 🔧 Installation sur le navigateur

### Pour Google Chrome :
1. Ouvrez un nouvel onglet et allez à l'adresse : `chrome://extensions/`
2. En haut à droite, **activez le "Mode développeur"**.
3. Cliquez sur le bouton **"Charger l'extension non empaquetée"** (ou "Load unpacked").
4. Sélectionnez le dossier `aegisscan-non-blocking` qui se trouve à la racine de ce projet.
5. L'extension AegisScan apparaîtra dans votre liste d'extensions.

### Pour Microsoft Edge :
1. Ouvrez un nouvel onglet et allez à l'adresse : `edge://extensions/`
2. Dans le menu de gauche, **activez le "Mode développeur"**.
3. Cliquez sur **"Charger l'extension décompressée"**.
4. Sélectionnez le dossier `aegisscan-non-blocking` à la racine de ce projet.

## 🔐 Activation
Une fois l'extension installée :
1. Assurez-vous d'être connecté à l'application AegisScan.
2. L'extension va se synchroniser automatiquement avec l'application. 
3. Vous pouvez cliquer sur l'icône de l'extension dans la barre d'outils de votre navigateur : elle devrait afficher **"Protection active"**.

**C'est tout !** Vos clics sur les liens seront désormais automatiquement analysés pour vous protéger contre les menaces potentielles.

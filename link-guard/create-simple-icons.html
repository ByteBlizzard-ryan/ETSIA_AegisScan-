📋 Instructions d'installation

Étape 1 : Cliquez sur "Générer toutes les icônes" ci-dessus
Étape 2 : Téléchargez les 3 icônes en cliquant sur les liens de téléchargement
Étape 3 : Placez les fichiers PNG dans le dossier link-guard/icons/
Étape 4 : Installez l'extension dans Chrome/Edge via le mode développeur

🚀 Installation de l'extension

Chrome : chrome://extensions → Mode développeur → Charger l'extension non empaquetée

Edge : edge://extensions → Mode développeur → Charger l'extension décompressée
